## The rules that decide whether a coupon actually works

Shoe Carnival's promo system has exclusions, and knowing them separates a real discount from a checkout error message.

The price tags themselves encode the rules. Promotional prices end in **.98** and accept coupons. Clearance items with pink tags end in **.00**, keep marking down over time, and still accept coupons. Regular-price items ending in **.99** and certain brands' everyday prices ending in **.00** are full price. Items with yellow tags are excluded from coupons entirely.

Brand exclusions exist too. Vans has historically been a coupon-excluded brand at Shoe Carnival. That matters more than it sounds, because the Vans shoes Shoe Carnival sells are made-for-outlet versions anyway: its "Asher" Slip On lists at $49.99 while Vans' own "Classic" Slip On lists at $50, so there's little price advantage either way, and a percentage-off code likely won't touch them.

The big site-wide codes floating around aggregators, like 25% off storewide, carry their own carve-outs — typically excluding doorbusters and "Web Busters" promotional items. A 25% code applied to a doorbuster-heavy cart will quietly discount less than the headline suggests.

A useful quirk: while you can only use one coupon per order, a coupon **can be applied to items already on sale**. Stacking a code onto .98 promotional pricing is where the numbers get interesting.
